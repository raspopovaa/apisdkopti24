# Контракт и развитие API

## Публичная поверхность

Точка входа — `apisdkopti24.APIClient`. Методы вызываются через доменные фасады, например `client.cards`, `client.transactions`, `client.reports`. Сигнатуры, модели и исключения являются публичным контрактом и не меняются без миграционной заметки.

## Каталог

Фактический перечень строится из runtime registry и отображается в `docs/methods.md`. На текущем срезе зарегистрированы и опубликованы 89 операций, включая подтверждённые операции МПК/QR из контракта QR 1.0.4. Числа необходимо пересчитывать генераторами, а не обновлять вручную без проверки.

## Добавление метода

1. Найти раздел в основной или QR-спецификации и записать версию документа.
2. Проверить HTTP-глагол, API version, endpoint, обязательные заголовки, session/contract, DEMO и billable.
3. Добавить нормализованный контракт/registry entry с корректным retry class.
4. Создать строгие request-модели и совместимые response-модели.
5. Реализовать async keyword-only метод в соответствующем сервисе через executor.
6. Добавить тесты без сети и обновить генерируемую документацию.

## QR

QR 1.0.4 является разрешённым источником. До написания кода составить mapping всех QR/МПК операций. Не смешивать QR-платёж с выпуском виртуальной карты только из-за похожих сущностей. Для каждой операции отдельно определить идемпотентность, состояние платежа, повторяемость запроса, таймаут, ошибки и чувствительные данные.

## Совместимость

- Поддерживать Python 3.11–3.14 и Pydantic 2.
- Breaking change требует major-версии или явно утверждённой миграции.
- Добавление необязательного метода/поля обычно backward-compatible.
- Серверные дополнительные поля не должны ломать response parsing.
- Переименование Python-параметра требует deprecation path, если интерфейс опубликован.

## Проверка контрактов

```bash
uv run python scripts/verify_external_contract.py specifications/api-methods.yaml
uv run python scripts/verify_api_contract.py specifications/api-contract-v1.1.60.yaml
uv run python scripts/audit_spec_contract.py --mode verified
uv run python scripts/audit_spec_contract.py --mode audit
```

Audit-отчёт — диагностический артефакт. Несовпадение нельзя скрывать исключением из генератора без документированного основания.
