# Группы карт

Группы объединяют карты договора: на группу можно назначить лимиты и ограничения сразу для всех её карт.

| Пример | HTTP | Изменяет данные | Тарифицируется | DEMO |
|---|---|:---:|:---:|:---:|
| [Список групп карт](get_card_groups.md) | GET `cardGroups` | Нет | Нет | Да |
| [Создание и переименование группы карт](set_card_group.md) | POST `setCardGroup` | Да | Да | Да |
| [Добавление и удаление карт в группе](set_cards_to_group.md) | POST `setCardsToGroup` | Да | Да | Да |
| [Удаление группы карт](remove_card_group.md) | POST `removeCardGroup` | Да | Да | Да |
