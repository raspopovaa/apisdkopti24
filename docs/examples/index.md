# Учебные примеры

Каждый пример — короткий запускаемый скрипт и страница с его разбором:

- **Пример** — код вызова метода с обработкой характерных ошибок;
- **Что отправляет SDK** — HTTP-запрос и таблица полей: где передаётся каждое
  поле и в каком виде;
- **Что возвращает API** — пример ответа, модель проверки и вывод примера;
- **Ошибки** — ответы API с ошибкой, исключения SDK с их текстом, причины и
  что делать; отдельно — ошибки, которые SDK находит до отправки запроса.

Запросы и тексты исключений на страницах не написаны вручную: генератор
выполняет каждый пример на подставном транспорте и записывает, что отправил
и выбросил SDK. Проверка в CI не даёт примерам разойтись с кодом.

## Как запустить пример

1. Установите SDK: `pip install apisdkopti24`.
2. Создайте `.env` по образцу `.env.example`: `API_BASE_URL`, `API_KEY`,
   `API_LOGIN`, `API_PASSWORD` и `API_CONTRACT_ID`.
3. Замените в начале файла примера условные значения своими.
4. Выполните `python examples/methods/<раздел>/<метод>.py`.

Примеры, которые изменяют данные или тарифицируются, спрашивают подтверждение
перед вызовом. Начинайте с DEMO-стенда.

## Разделы

- [Авторизация](auth/index.md) — Вход с выбором договора, статистика обращений к API по тарифу и завершение серверной сессии.
- [Группы карт](card_groups/index.md) — Группы объединяют карты договора: на группу можно назначить лимиты и ограничения сразу для всех её карт.
- [Топливные карты](cards/index.md) — Получение списка карт и сведений о карте, блокировка, комментарии, водители и сброс счётчика неверных вводов PIN.
- [Договоры и документы](contracts/index.md) — Баланс и реквизиты договора, платежи, счета, закрывающие документы и заказ новых карт.
- [Справочники и АЗС](dictionaries/index.md) — Общие справочники (статусы, товары, регионы, офисы) и поиск торговых точек с фильтрами.
- [Электронный кошелёк](ewallet/index.md) — Перевод карты на кошелёк и обратно, пополнение кошелька карты с договора и возврат средств на договор.
- [Итоговые цены](final_prices/index.md) — Расчёт цены товаров для карты на конкретной АЗС с учётом тарифа договора и проверка возможности покупки.
- [Приглашения](invites/index.md) — Регистрация пользователей по приглашению: создание, список, повторная отправка, продление и удаление.
- [Продуктовые лимиты](limits/index.md) — Лимиты расхода по карте или группе карт: объём в литрах или сумма в рублях за сутки, неделю, месяц и другие периоды.
- [Региональные ограничения](region_limits/index.md) — Где можно пользоваться картой: разрешающие и запрещающие ограничения по стране, региону и конкретной АЗС.
- [Отчёты](reports/index.md) — Заказ отчётов по договору и картам, список заказанных отчётов и скачивание готовых файлов.
- [Товарные ограничители](restrictions/index.md) — Какие товары можно или нельзя покупать по карте: разрешающие и запрещающие ограничители по типам и группам продуктов.
- [Шаблоны виртуальных карт](templates/index.md) — Шаблон задаёт тип виртуальной карты и её лимиты, товарные и географические ограничения. Карты, выпущенные по шаблону, получают эти настройки.
- [Транзакции](transactions/index.md) — Операции по картам и договору: покупки на АЗС, возвраты и корректировки за период, детали отдельной транзакции.
- [Пользователи](users/index.md) — Водители и другие пользователи клиента: список, создание, привязка к картам и договорам, удаление.
- [Виртуальные карты и оплата по QR](virtual_cards/index.md) — Выпуск виртуальных карт, мобильный профиль карты (МПК) на устройстве водителя и платёжная строка для оплаты по QR-коду.
