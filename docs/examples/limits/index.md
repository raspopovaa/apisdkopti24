# Продуктовые лимиты

Лимиты расхода по карте или группе карт: объём в литрах или сумма в рублях за сутки, неделю, месяц и другие периоды.

| Пример | HTTP | Изменяет данные | Тарифицируется | DEMO |
|---|---|:---:|:---:|:---:|
| [Список продуктовых лимитов](get_limits.md) | GET `limit` | Нет | Нет | Да |
| [Установка продуктового лимита](set_limit.md) | POST `setLimit` | Да | Да | Да |
| [Удаление продуктового лимита](remove_limit.md) | POST `removeLimit` | Да | Да | Да |
