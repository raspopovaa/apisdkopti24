# Приглашения

Регистрация пользователей по приглашению: создание, список, повторная отправка, продление и удаление.

| Пример | HTTP | Изменяет данные | Тарифицируется | DEMO |
|---|---|:---:|:---:|:---:|
| [Создание приглашения](create_invite.md) | POST `invites` | Да | Да | Нет |
| [Список приглашений](get_invites.md) | GET `invites` | Нет | Нет | Да |
| [Повторная отправка приглашения](resend_invite.md) | GET `invites/{invite_id}/send` | Да | Да | Нет |
| [Продление приглашения](prolong_invite.md) | POST `invites/{invite_id}/prolong` | Да | Да | Нет |
| [Удаление приглашения](delete_invite.md) | DELETE `invites/{invite_id}` | Да | Нет | Да |
