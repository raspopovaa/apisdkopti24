# Товарные ограничители

Какие товары можно или нельзя покупать по карте: разрешающие и запрещающие ограничители по типам и группам продуктов.

| Пример | HTTP | Изменяет данные | Тарифицируется | DEMO |
|---|---|:---:|:---:|:---:|
| [Список товарных ограничителей](get_restrictions.md) | GET `restriction` | Нет | Да | Да |
| [Установка товарного ограничителя](set_restriction.md) | POST `setRestriction` | Да | Да | Нет |
| [Удаление товарного ограничителя](remove_restriction.md) | POST `removeRestriction` | Да | Да | Да |
