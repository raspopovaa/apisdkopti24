# `DateRangePaginationQuery`

Модель данных SDK.

!!! info "Назначение Pydantic"
    Тип модели: **request**. Правила ниже применяются, когда вызывающий код явно создаёт `DateRangePaginationQuery` или вызывает `DateRangePaginationQuery.model_validate(payload)`. Наличие request-модели не означает, что каждый метод SDK автоматически создаёт её: фактический входной контракт определяется сигнатурой соответствующего сервисного метода.

| Заполнение по имени поля | `True` | Разрешено использовать имя поля наряду с alias. |
