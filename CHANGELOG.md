# Changelog

## Unreleased

### Changed

- request metadata включена в единый `OperationSpec`, а `EndpointSpec` удалён;
- внутренние поля запроса переименованы в `query`, `form` и `json_body`;
- удалён legacy-вход `AsyncTransport`: transport принимает только `PreparedRequest`;
- `Content-Type` формируется только для фактически переданного тела;
- повторяющиеся части query/form вынесены в типизированные request DTO;
- добавлена фиксированная wire-матрица и параметризованная проверка всех 89 операций.

## 3.2.1 — 2026-09-06

- добавлена полная матрица запросов и ответов для 89 операций;
- модели данных приведены к типам, описаниям и обязательности полей спецификаций 1.1.60 и QR 1.0.4;
- исправлены нормализованные пути вложенных полей и алиасы wire-ответов;
- расширены контрактный аудит и проверки документации.

## 3.2.0 — 2026-09-06

### Changed

- маршрут, response-модель и политики выполнения объединены в `OperationSpec`;
- параметры вызова и transport-запрос представлены `RequestOptions` и
  `PreparedRequest` вместо нетипизированного `**kwargs`;
- retry, rate limiting и атомарная файловая запись вынесены из `AsyncTransport`;
- executor-протоколы разделены для JSON, байтовых и файловых ответов;
- удалён дублирующий `_ServiceFacade`, при сохранении совместимого `client.cards`;
- `TemplatesService` разделён на четыре узкие внутренние группы операций;
- provisional-контракты не повышались без подтверждения первичным источником;
  полный audit остаётся очередью дальнейшей типизации.

## 3.1.1 — 2026-09-06

### Changed

- публичный Python-модуль переименован из `apisdkopti24` в `apisdkopti24`;
- примеры, документация, тесты и контрактные ссылки обновлены для нового импорта.

## 3.1.0 — 2026-09-06

### Added

- типизированный жизненный цикл МПК и формирование платёжной BER-TLV строки для QR-кода;
- локальная проверка PIN, типа сброса и длины параметров устройства;
- отдельный контракт QR API 1.0.4 и руководство по безопасной QR-оплате.

### Changed

- QR/MPC-методы используют явные параметры вместо нетипизированного `payload`;
- ответы списка МПК и генерации оплаты валидируются специализированными моделями.

## 3.0.3 — 2026-09-06

### Fixed

- синхронизированы публичные сигнатуры транзакций с контрактом API 1.1.60;
- обновлены тестовые ответы авторизации для строгих response-моделей;
- удалены конфликтные копии файлов и добавлена CI-защита от их повторного появления.

## 3.0.0 — unreleased

### Changed

- `APIClient.session_id` и `APIClient.contract_id` стали read-only;
- добавлены `select_contract()`, `restore_session()` и `clear_session()`;
- retry ограничен общим deadline и единым attempt budget;
- retry backoff использует full jitter;
- публичные сервисы раньше отклоняют пустые ID, списки и неверную пагинацию.

### Fixed

- batch-операции лимитов и ограничений больше не допускают смешанные договоры;
- timeout попытки не может превышать оставшееся время общей операции.
