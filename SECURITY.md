# Безопасность

## Поддерживаемые версии

Исправления безопасности выходят только для последней опубликованной версии
линии 0.0.x. Пока SDK в разработке, более ранние версии не обновляются:
переходите на последнюю.

## Как сообщить об уязвимости

Не создавайте публичный issue. Сообщите через закрытый отчёт GitHub:
вкладка **Security** → **Report a vulnerability** в репозитории
[raspopovaa/apisdkopti24](https://github.com/raspopovaa/apisdkopti24/security/advisories/new).

Укажите версию SDK, шаги воспроизведения и возможные последствия. Не прикладывайте
реальные ключи API, пароли, session ID, номера карт и персональные данные: замените
их условными значениями.

Мы подтвердим получение отчёта и сообщим план исправления.
После выпуска исправления уязвимость будет описана в GitHub Security Advisory и
в CHANGELOG.

## Вне рамок SDK

Уязвимости самого API оператора, личного кабинета и мобильных приложений
сообщайте оператору топливных карт.

Как SDK обращается с секретами и персональными данными, описано в
[docs/security.md](docs/security.md).
